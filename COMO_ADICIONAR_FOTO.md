# 📸 Como Adicionar Sua Foto Profissional

## 🎯 Passo a Passo

### 1. **Prepare sua imagem**
- **Nome do arquivo:** `profile.jpg`
- **Dimensões ideais:** 300x300px (quadrado)
- **Formato:** JPG ou PNG
- **Tamanho máximo:** 500KB
- **Qualidade:** Alta resolução, boa iluminação

### 2. **Salve no local correto**
```
Portifolio/
├── assets/
│   └── profile.jpg  ← Salve sua foto aqui
├── index.html
├── css/
└── js/
```

### 3. **Usando o Windows Explorer**
1. Navegue até a pasta: `C:\Users\Felipe Delmondes\Desktop\repo\Portifolio\assets\`
2. Cole sua foto renomeada como `profile.jpg`
3. Substitua qualquer arquivo existente

### 4. **Otimização da imagem (opcional)**
Se quiser otimizar sua foto:
- Use um editor como GIMP, Photoshop ou ferramentas online
- Redimensione para 300x300px
- Salve com qualidade 85-90%

### 5. **Faça o commit e push**
```bash
git add assets/profile.jpg
git commit -m "feat: Adiciona foto profissional do perfil"
git push
```
