# Instruções para adicionar sua foto profissional

## Como adicionar a imagem:

1. **Salve sua foto como `profile.jpg`** nesta pasta (assets/)
2. **Dimensões recomendadas:** 300x300px
3. **Formato:** JPG (otimizado para web)
4. **Tamanho máximo:** 500KB
