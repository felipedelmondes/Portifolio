# Placeholders para imagens do portfólio

## Como adicionar suas próprias imagens:

### 1. Foto de perfil (profile.jpg)
- Dimensão recomendada: 300x300px
- Formato: JPG ou PNG
- Substitua este arquivo pela sua foto profissional

### 2. Imagens dos projetos
- project1.jpg - Dimensão: 400x200px
- project2.jpg - Dimensão: 400x200px  
- project3.jpg - Dimensão: 400x200px
- Formato: JPG ou WebP para melhor performance

### 3. Favicon
- favicon.ico - Dimensão: 32x32px ou 16x16px
- Formato: ICO
- Pode usar ferramentas online como favicon.io para gerar

### Dicas:
- Use imagens otimizadas para web
- Mantenha o tamanho dos arquivos pequenos (< 500KB por imagem)
- Para projetos, capture telas das suas aplicações ou use mockups
- A foto de perfil deve ser profissional e de boa qualidade

### Se não tiver imagens próprias:
O JavaScript do portfólio automaticamente gera placeholders SVG bonitos para demonstração.
